## Findings (by hand)

Checked against Barnett (1978, 1980), Diewert (1976), Rotemberg, Driscoll and Poterba (1995), Barnett and Serletis
(1990) and the Consumer Price Index Manual (ILO et al. 2004, Chapter 19).

| # | Where | Finding | Action |
|---|---|---|---|
| 1 | `dmai()`, Barnett | `logbase = NULL` meant base 10, so `DMAI` was 0.434 times the log growth in percent; the Divisia index uses natural logarithms | default changed to the natural logarithm; `logbase = 10` reproduces 0.5.0 (test-legacy); NEWS, Corrections |
| 2 | `dmai()` | `method = c("Barnett", "Hancock")` used in `if (method == "Hancock")`: a call without `method` stops with an error in R >= 4.2 | `method` matched to its first value (default "Barnett") |
| 3 | `dmai()` | the benchmark is the largest component rate, so that component has a user cost of zero and no weight | kept as the default for compatibility; `benchmark` (column, number or vector) with the upper envelope; the interpretation warns |
| 4 | `dmai()` | rates in percent enter `(R - r) / (1 + R)` as if decimal (1 + 14 for 14 percent) | no effect on the shares (the factor cancels); user costs now computed with decimal rates (`percent`) |
| 5 | `dmai()` | every column other than `Date` must be named letters + digits; any other column (a benchmark, a label) breaks the reshape | columns named by `date`, `x`, `r`; other columns are ignored |
| 6 | `dmai()`, Hancock | the help page gives no source for the method; it is the Divisia shares with simple growth rates | kept as in 0.5.0; documented as such, with Hancock (1985) as the source of the user-cost approach for the financial firm |
| 7 | `dmai()` | only the growth rate was returned | index level, value in money units, dual price index, shares and user costs added |
| 8 | Imports | dplyr, magrittr, stringr, tibble, tidyr (and ggplot2 attached with `@import`) for one reshape and a grouped sum | matrix computations and data.table; 5 to 7 times faster (vignette 5) |
| 9 | example | random data without a seed (`runif`) | the examples use the simulated data set `money_sim`; the 0.5.0 example with a seed is the legacy snapshot |
