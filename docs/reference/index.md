# Package index

## Monetary aggregates

Divisia (Barnett 1980), Fisher ideal, simple-sum and currency equivalent
indexes.

- [`dmai()`](https://myaseen208.com/dmai/reference/dmai.md) : Divisia
  monetary aggregates index
- [`dmai_compare()`](https://myaseen208.com/dmai/reference/dmai_compare.md)
  : Monetary aggregates by every method

## Weights and dispersion

- [`dmai_user_cost()`](https://myaseen208.com/dmai/reference/dmai_user_cost.md)
  : User costs and expenditure shares of monetary assets
- [`dmai_moments()`](https://myaseen208.com/dmai/reference/dmai_moments.md)
  : Divisia second moments
